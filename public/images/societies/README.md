# Society Official Images

Place official IEEE society banner and promotional images in this directory to visually guide and appeal students to join the specialized societies.

### Recommended Specifications:
- **Aspect Ratio**: 16:9 (or 4:3 landscape)
- **Resolution**: 800×450px or 1200×675px (JPG, PNG, or WebP)
- **Style**: High quality action shots, lab work, innovation events, official society hero graphics, or branding banners.
